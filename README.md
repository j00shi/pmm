# Package Manager Manager

Package Manager Manager (PMM) is a tool designed to help developers manage multiple package managers in a unified way. You may have wantet to change your Linux distribution and found yourself wondering if you forgot to install a package you had on your previous system. PMM allows you to easily check for installed packages across different package managers and distributions, making it easier to maintain consistency in your development environment.

## Installation

Windows: `winget install pmm`
Mac: `brew install pmm`
Linux:

```bash
sudo apt install pmm
sudo dnf install pmm
```

## Usage

- use the `pmm` cli to see possible commands and options.
