## What is PMM?

**Package Manager Manager (PMM)** is a cross-platform CLI tool designed to help developers manage packages across multiple package managers in a unified way.

If you have ever switched Linux distributions or set up a fresh workstation and wondered *"Which tools did I have installed on my previous machine?"*, PMM is built for you.

## Core Goals

- **Unified visibility** — Inspect installed packages across `winget`, `brew`, `apt`, and `dnf` through one consistent CLI.
- **Effortless distro switching** — Compare your current machine against a previous snapshot to immediately spot missing packages.
- **Reproducible environments** — Keep your daily CLI tools and dev dependencies aligned across machines.

## Quick Verification

Once PMM is installed, run the CLI without arguments (or with `--help`) to inspect available commands and options:

```bash
pmm --help
```
