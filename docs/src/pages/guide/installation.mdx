## Build from Source

Make sure you have **Java (JDK)** and **Maven** installed, then clone and build the project:

```bash
git clone https://github.com/j00shi/pmm.git
cd pmm
mvn package
```

## Verify Installation

Confirm that `pmm` is available in your `PATH`:

```bash
pmm --version
```
